# Logo

Put the official Diamondback Energy logo in this folder as `logo.svg`.

- Use the version made for **dark backgrounds** (white or light-colored), because the header band is the dark brand color.
- SVG is best. A PNG works too: name it `logo.png` and change `src="assets/logo.svg"` in `index.html` to `assets/logo.png`.
- The header shows it 36px tall. Width scales automatically.
- Until a logo file is added, the header shows the words "DIAMONDBACK ENERGY" instead.

Get the logo file and brand colors from Diamondback's Corporate Communications or Marketing team, and confirm the Career Connections branding is approved before going live.
